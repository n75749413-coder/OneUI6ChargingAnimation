# Charging Animation — проект для Samsung Galaxy A6+ / Android 10

Небольшое Android-приложение для показа короткой анимации зарядки. Оно не требует root и не меняет системные файлы.

## Что делает текущая версия
- Чёрный полноэкранный фон.
- Вращающееся зелёное кольцо и белая молния.
- Считывает настоящий процент заряда телефона и рисует его в центре.
- Закрывается примерно через 3 секунды.

Это стилизованная анимация, а не извлечённая оригинальная анимация Samsung One UI 6. Цвет пока постоянный зелёный; определение режимов быстрой/супербыстрой зарядки ещё не реализовано.

## Как получить APK без сборки на своём компьютере
В проект добавлен GitHub Actions workflow для облачной сборки. Понадобится GitHub-аккаунт:
1. Создай на GitHub новый пустой репозиторий.
2. Загрузи содержимое этой папки в репозиторий (не сам ZIP-файл, а файлы внутри него).
3. Открой вкладку **Actions** и выбери **Build Android APK**.
4. Нажми **Run workflow** и дождись завершения сборки.
5. В завершённом запуске внизу страницы открой **Artifacts** и скачай `ChargingAnimation-debug-apk`.
6. Распакуй ZIP артефакта — внутри будет `app-debug.apk`.

Также сборка запускается автоматически после push в ветку `main` или `master`.

## MacroDroid
После установки APK можно создать макрос:
- Триггер: **Питание подключено**.
- Действие: **Запустить приложение** → `Charging Animation`.

Проверь запуск вручную перед настройкой MacroDroid. На некоторых версиях Android/One UI запуск полноэкранного окна поверх экрана блокировки может ограничиваться системой.

## Ограничения
- APK здесь пока не собран и не протестирован на реальном A6+.
- Цвет кольца всегда зелёный; распознавание быстрой зарядки пока не добавлено.
- Для запуска при подключении зарядки нужен MacroDroid или другой механизм автоматизации.
